# aguimes-imagenes

Repositorio público de AGÜIMES AL DÍA:

- `img/`: tarjetas de las noticias (las usa Metricool para Facebook).
- `noticias.json`: noticias de los últimos 7 días para la web
  [mitiempo.sytes.net/noticias](https://mitiempo.sytes.net/noticias/), sección «Agüimes al Día».
  Lo escribe la rutina con `generador/feed.py` del repositorio aguimes-al-dia.
